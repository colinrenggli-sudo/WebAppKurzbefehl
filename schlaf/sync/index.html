Code für den Server

Einen Moment …

  1. Code kopieren.
  2. Im Terminal des Servers ins Einrichtungsskript einfügen, dort wo Code: steht.
  3. Fertig – ab dann holt der Server die Daten von selbst.

Der Code ist nur wenige Minuten gültig und einmal verwendbar. Diese Seite speichert und sendet nichts; alles steht ausschliesslich in der Adresszeile deines Browsers.
