Ansprache

Firma links wählen, Tonalität oben, Text unten anpassen. Der Text nennt immer das konkrete Inserat.
Vor dem Senden: Das Schweizer UWG kennt keine B2B-Ausnahme. Was uns trägt, ist, dass eine einzeln recherchierte, einzeln formulierte Nachricht gar keine «Massenwerbung» ist. Darum: jede Mail von Hand anfassen, den Bezug zum konkreten Inserat drin lassen, vollständige Absenderadresse, ein Satz woher die Angaben stammen, ein Satz zur Abmeldung. Lieber zwanzig angepasste Mails pro Tag als fünfhundert gleiche — rechtlich wie in der Antwortquote. Und wer «nein» sagt, kommt auf eine dauerhafte Sperrliste, nicht bloss aus dieser Runde raus. Details in RECHERCHE.md, Abschnitt Recht.
